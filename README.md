# AOS-Bench project page

English: https://aos-bench.github.io/

中文：https://aos-bench.github.io/zh.html

Static research page with local media and no build-time dependencies. The research
snapshot is manuscript commit `d9e71fa40af05e327c61a0920dae9d4a5482e10b`
(11 November 2026), before the first rebuttal revision. The linked arXiv record and
downloadable manuscript snapshot have separate version histories; see `assets/release.json`.

Figures, video and research text are credited to the AOS-Bench authors. The bundled
subset of Noto Sans CJK SC is distributed under the SIL Open Font License; see
`assets/NotoSansSC-OFL.txt`. Narration uses a stock synthetic English voice.

The GitHub Actions workflow publishes this directory to GitHub Pages. Do not add
private experiment logs, local credentials, rebuttal material or internal PR notes.
